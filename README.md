# beacio Agent Skills

Auto-generated agent skills used by AI coding assistants.

## Install
```bash
npx skills add https://github.com/wklm/beacio-sdk
```

## Available Skills

### beacio-developer
For contributors working on the beacio Safari Extension itself — Swift CoreBluetooth code, TypeScript extension shell, IPC relay, background sync, beacon scanning, simulator verification, Xcode MCP tools.

### beacio-sdk-consumer
For developers using the beacio SDK to build BLE web apps — polyfill integration, API reference, troubleshooting, copy-paste recipes.

## Source of Truth
These skills are auto-generated from the private monorepo at `wklm/beacio-sdk/skills/`. Do not open PRs here — contribute to the source repo.

## Versioning
Each skill's `SKILL.md` frontmatter includes a version field. Git tags align with beacio releases.
